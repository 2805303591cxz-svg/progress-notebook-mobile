# 进步记录本手机版：方法说明

## 核心目标

每天睡前用不超过三分钟，写下一件今天真实发生的收获或进步；第二天仍能看见它留下的光。

## 原理 → 界面动作

| 原理 | 界面动作 | 可验证结果 |
|---|---|---|
| 记录门槛越低，越容易坚持 | 今天页只保留标题、正文、标签和保存按钮 | 只写一句正文也能保存 |
| 进步需要被看见，才有反馈 | 记录后成长星轨点亮、连续天数更新 | 保存后统计与星轨立即变化 |
| 睡前需要温和提示，而不是打卡压力 | 智能问候、每天轮换的问题提示 | 不强制字数、不惩罚断签 |
| 手机和电脑都可能使用 | 本地优先写入 + Cloudflare D1 同步码 | 两台设备使用同一同步码后看到同一记录 |
| 离线也应该能写 | IndexedDB 本地保存 + Service Worker 缓存 | 断网重开仍能阅读和新增 |
| 删除不能跨设备复活 | 删除时写入墓碑记录 | 同步后被删记录不会重新出现 |
| 个人文字应尽量少上传 | 只同步日期、标题、正文、标签、时间戳 | 无图片、无设备信息、无浏览数据 |

## 功能红线

1. 不把用户记录打进公开静态文件；旧版记录只写入用户专属同步空间。
2. 同步只传文字业务数据，不做账号体系，不采集联系人、位置、设备标识；同步码不进入公开仓库。
3. 合并规则：同日期取 `updatedAt` 更新的记录；删除使用墓碑。
4. 没有设置同步码时，App 仍可完整离线使用，只是不跨设备共享。
5. 保存失败必须可见；离线时明确显示“等待同步”，不能假装已上传。
6. 首次进入不得要求注册。

## 有意不做

- 不做排行榜、社区、积分商城。
- 不做图片/语音上传。
- 不做多个日记本；当前只保留每天一条、可随时更新。
- 不承诺后台定时推送提醒；手机系统限制下，PWA 关闭后无法稳定本地定时通知。
